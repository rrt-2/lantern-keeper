# 등불지기: 새벽까지

> 밤새 몰려오는 그림자 괴물을 피해 작은 등불 정령으로 새벽까지 살아남는 **로그라이크 탄막 서바이벌 웹 게임**

- **장르:** 로그라이크 · 서바이벌 · 탄막 (자동 공격 + 이동 회피)
- **플랫폼:** 웹 브라우저 (PC · 모바일), 설치 필요 없음
- **바로 플레이:** https://rrt-2.github.io/lantern-keeper/
- **구성:** HTML 파일 하나 (외부 이미지·라이브러리 없음, 그래픽·사운드·음악 모두 코드로 생성)

---

## 1. 실행 방법

| 방법 | 설명 |
|---|---|
| 웹에서 실행 | https://rrt-2.github.io/lantern-keeper/ 에 접속하면 바로 플레이할 수 있습니다. |
| 파일로 실행 | 이 저장소의 `index.html`을 내려받아 더블클릭하면 크롬·엣지 등에서 실행됩니다. |

> 인터넷이 없으면 제목 글꼴만 기본 글꼴로 바뀌고 게임은 그대로 작동합니다.

## 2. 조작법

| 동작 | PC | 모바일 |
|---|---|---|
| 이동 | `W` `A` `S` `D` 또는 방향키 | 화면을 누른 채 끌기 (가상 조이스틱) |
| 공격 | 자동 | 자동 |
| 카드 선택 | 클릭 또는 `1` `2` `3` | 터치 |
| 장치 사용 (슬롯머신·상인·제단) | `E` | 화면 아래 버튼 |
| 일시정지 | `Esc` 또는 `P` | 오른쪽 위 버튼 |

## 3. 게임 모드

- **10분 생존:** 10분을 버티면 새벽이 밝아 오며 클리어. 8분에 보스 "그림자 군주" 등장. 클리어 뒤 그대로 무한 모드로 이어갈 수 있음.
- **무한 모드:** 끝없는 밤. 2분 30초마다 "깊은 밤" 단계가 오르며 변이(피의 달, 탄막의 밤 등)가 쌓이고, 보스 3종(그림자 군주·서리 여왕·용암 거인)이 5분마다 더 강해져 돌아옴. 15·20·30·45·60분 생존 메달, 기록 TOP 5 저장.
- **난이도:** 보통 / 어려움 (적 체력 1.45배, 공격력 1.3배, 등장 속도 1.3배)

## 4. 주요 시스템

### 성장
- **일반 무기 18종** (최대 Lv 5) + **무기 합성 9종** — 짝이 맞는 두 무기를 Lv 5로 올리면 강력한 합성 무기로 진화
- **패시브 능력 13종** (공격·방어·이동 등). 방어 계열: 수호 방패, 나무껍질 갑옷, 정화의 종(적 탄환 제거), 그림자 걸음(회피), 불사조 깃털(부활)
- **전설 무기 6종** (최대 Lv V) — 강적·보스가 떨어뜨리는 전설 상자에서만 획득
- **신화 합성 3종** — Lv V 전설 무기 두 개를 합쳐 탄생
- **초월 강화** — 일반 강화를 모두 마친 뒤에도 계속 성장
- **영구 강화 (메타 진행)** — 판이 끝나면 금화가 보관함에 쌓이고, 9종의 영구 능력을 구매해 다음 판을 더 강하게 시작

### 세계
- **바이옴 4종:** 고요한 숲 · 서리 설원 · 잿불 화산(화산탄 주의) · 독안개 늪 — 지역마다 지형, 날씨, 규칙(경험치·적 능력치)이 다름
- **특수 장치:** 운명의 슬롯머신(미니게임), 떠돌이 상인(상점), 저주의 제단(위험 대신 보상), 달빛 샘(회복), 보물 고블린
- **적 10종 + 보스 3종**, 탄환 발사 전 조준선·경고 원 표시

### 편의 · 접근성
- 첫 판 단계별 **튜토리얼** (건너뛰기·다시 보기 가능)
- **배경 음악** (평상시·보스전·새벽 3가지 분위기, 코드로 실시간 생성), 효과음·음악 음량 조절
- 화면 흔들림·피해 숫자·**내 공격 이펙트 밝기** 조절 (후반에 적 탄환을 잘 보이게)
- 저사양 기기에서 프레임이 떨어지면 자동으로 광원 효과를 줄이는 **적응형 품질**
- 다른 탭으로 전환 시 자동 일시정지, 진행 상황·설정 자동 저장 (브라우저 localStorage)

## 5. 기술 구성

| 항목 | 내용 |
|---|---|
| 언어 | HTML5, CSS3, JavaScript (프레임워크·라이브러리 없음) |
| 렌더링 | Canvas 2D — 스프라이트를 시작 시 코드로 미리 그려 캐싱, 별도 조명 캔버스로 동적 조명(destination-out) 처리, 가산 혼합(lighter)으로 발광 효과 |
| 충돌 처리 | 64px 공간 분할 격자(spatial grid)로 수백 개 적·탄환 충돌을 효율적으로 계산 |
| 사운드 | Web Audio API — 효과음은 오실레이터, 배경 음악은 룩어헤드 스케줄러로 화음·베이스·아르페지오·드럼을 실시간 합성 |
| 저장 | localStorage (최고 기록, 영구 강화, 설정) |
| 반응형 | 모바일 터치 조이스틱, 안전 영역(safe-area) 대응, 화면 크기별 HUD 배치 |

## 6. 배포 방법 (GitHub Pages)

1. [github.com](https://github.com)에 로그인하고 오른쪽 위 **+ → New repository**를 누릅니다.
2. 저장소 이름을 정하고 (예: `lantern-keeper`) **Public**으로 만듭니다.
3. 게임 파일 이름을 **`index.html`** 로 바꿉니다. (GitHub Pages는 `index.html`을 첫 화면으로 엽니다)
4. 저장소 화면에서 **Add file → Upload files**로 `index.html`과 이 `README.md`를 올리고 **Commit changes**를 누릅니다.
5. 저장소의 **Settings → Pages**에서 Source를 **Deploy from a branch**, Branch를 **main / (root)** 로 정하고 **Save**를 누릅니다.
6. 1~2분 뒤 같은 화면 위쪽에 `https://아이디.github.io/lantern-keeper/` 주소가 나타납니다. 이 링크를 제출하면 됩니다.

> 다른 방법: [itch.io](https://itch.io)에서 새 프로젝트를 만들고 "Kind of project"를 **HTML**로 정한 뒤, `index.html`을 zip으로 압축해 올리면 게임 페이지가 생깁니다.

## 7. 개발 과정 요약

1. 핵심 루프 구현 — 이동, 자동 공격, 적 추적, 경험치·레벨업 카드
2. 그래픽 개편 — 동적 조명, 파티클, 스프라이트 음영, 바닥 텍스처
3. 콘텐츠 확장 — 무기·합성, 보스 연출, 무한 모드
4. 깊이 추가 — 전설·신화 무기, 방어 능력, 바이옴, 슬롯머신·상인 등 특수 장치
5. 후반 밸런스 — 자동 플레이 봇으로 수십 판을 시뮬레이션해 성장 곡선과 적 강화 속도를 조정 (무한 성장 버그, 시간 정지 상시 발동 버그 수정)
6. 완성도 — 영구 강화, 배경 음악, 튜토리얼, 음량·접근성 설정
